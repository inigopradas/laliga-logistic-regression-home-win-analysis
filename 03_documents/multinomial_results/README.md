# Multinomial Model Results

This directory contains the documents reporting the results of the multinomial
logistic regression analyses conducted in the project.

The analyses examine the final match outcome from the perspective of the home
team and are conducted for two study periods:

1. The 2024/2025 LaLiga season.
2. The combined 2022/2023, 2023/2024 and 2024/2025 LaLiga seasons.

For both study periods, the result documents include analyses based on
conceptual blocks of match variables and analyses focused on the starting
formations used by the home and visiting teams.

The reproducible R scripts used to generate these results are stored separately
in:

`02_scripts/multinomial_models/`
