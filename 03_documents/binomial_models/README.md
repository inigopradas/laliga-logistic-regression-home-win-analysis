# Binomial Model Results

This directory contains the documents reporting the results of the binomial
logistic regression analyses conducted in the project.

These files contain statistical outputs, result tables, graphical summaries
and written interpretations. The reproducible R scripts used to generate the
results are stored separately in:

`02_scripts/binomial_models/`
