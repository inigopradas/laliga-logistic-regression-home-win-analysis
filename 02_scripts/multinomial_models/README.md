# Multinomial Logistic Regression Models

This directory contains the R scripts used to prepare, estimate, simplify and
evaluate the multinomial logistic regression models developed in the project.

The analyses examine match outcomes from the perspective of the home team and
are conducted separately for:

1. The 2024/2025 LaLiga season.
2. The combined 2022/2023, 2023/2024 and 2024/2025 LaLiga seasons.

For each study period, the directory includes models based on conceptual blocks
of match variables and models focused on the starting formations used by the
home and visiting teams.
