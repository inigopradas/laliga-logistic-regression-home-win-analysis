# 2024/2025 Season Dataset

This directory contains the original dataset used for the analysis of the
2024/2025 LaLiga season.

## Dataset

- `variables_Estudio (9).xlsx`

## Description

The dataset contains match-level observations and variables used in the
binomial and multinomial logistic regression analyses of home-team match
outcomes.

The analyses include performance, contextual and tactical variables, together
with the initial formations used by the home and visiting teams.

## Data policy

The original Excel file must not be modified or overwritten.

Any cleaned, recoded or transformed version of the dataset should be stored in
the corresponding processed-data directory.

## Main R object

The dataset is generally imported into R using the object name:

`d`
